open-websearch serverless API

This deployment exposes the open-websearch MCP server and REST API over HTTPS with end-to-end encrypted payloads using X25519 ECDH and AES-256-GCM. No API keys are required.

Setup

  1. Generate server keys: open-websearch e2e-keygen
  2. Set OPEN_WEBSEARCH_E2E_PRIVATE_KEY in your platform environment
  3. Fetch the public key from /.well-known/open-websearch-e2e
  4. Send encrypted requests with X-E2E-Client-Public-Key

Endpoints

  • GET /health — public liveness check
  • GET /.well-known/open-websearch-e2e — server public key
  • GET /status — encrypted deployment status
  • POST /search — encrypted web search
  • POST /fetch-* — encrypted fetch routes
  • POST /mcp — encrypted MCP Streamable HTTP

See docs/serverless-deployment.md in the repository for full setup instructions.
