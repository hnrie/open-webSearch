open-websearch serverless API

This deployment exposes the open-websearch MCP server and REST API over HTTPS. Set OPEN_WEBSEARCH_API_KEY in your platform environment and send it as Authorization: Bearer <key> or X-API-Key: <key>.

Endpoints

  • GET /health — public liveness check
  • GET /status — deployment status and capabilities
  • POST /search — web search
  • POST /fetch-web — fetch public page content
  • POST /fetch-github-readme — fetch GitHub README
  • POST /fetch-csdn, /fetch-juejin, /fetch-linuxdo
  • POST /mcp — MCP Streamable HTTP (stateless)

MCP client example

{
  "mcpServers": {
    "web-search": {
      "url": "https://your-deployment.example.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

See docs/serverless-deployment.md in the repository for full setup instructions.
